# SIH2025_Prakalp_Pharmaseal
Prakalp Pharmaseal is a Complete Medicine Supply Chain Blockchain Ledger built for the Smart India Hackathon 2025. It Tracks All the Exact Stages from Manufacturing to Customer Hands, Capturing Tampering, Invalidation, Expiry, or Missing Packs to Immediately Block Further Travel or Transfers. https://prajwal250.github.io/SIH2025_Prakalp_Pharmaseal/
